# Флоу подключения канала

## Шаги владельца канала

1. Владелец открывает бота в MAX (или нажимает кнопку в Mini App)
2. `bot_started` → бот отвечает: «Добавьте меня как администратора в ваш канал»
3. Владелец добавляет бота как **ADMIN** с правами:
   - Читать сообщения
   - Публиковать сообщения
   - Редактировать сообщения
4. `bot_added` → `onBotAdded.ts`:
   - Регистрирует или находит пользователя в БД (`users`)
   - Создаёт скрытый групповой чат (или принимает ссылку на существующий)
   - Добавляет бота в этот чат как admin
   - Сохраняет запись в `channels` (owner_id, max_chat_id, discussion_chat_id)
   - Отправляет подтверждение владельцу

## Удаление канала

`bot_removed` → `onBotRemoved.ts`:
- Ставит `channels.is_active = false`
- Данные сохраняются (история комментариев остаётся)

## Скрытый групповой чат

- Создаётся ботом автоматически при подключении канала
- Подписчики канала **никогда** не видят этот чат
- Это просто техническое хранилище — все комментарии там в виде сообщений
- `channels.discussion_chat_id` хранит ID этого чата
