# ADR-001: Выбор технологического стека

**Дата:** 2026-04-07
**Статус:** Принято

## Контекст

Нужно выбрать стек для платформы комментариев MAX messenger.

## Решение

| Компонент | Технология | Причина |
|-----------|-----------|---------|
| Бот | Node.js + TypeScript | Нативная async/await, огромная экосистема, типизация |
| Backend API | Node.js + TypeScript + Express | Единый язык с ботом, общие типы через `shared/` |
| Mini App | React + Vite + TypeScript | Самый зрелый UI-фреймворк, быстрая сборка |
| База данных | PostgreSQL 15 | Реляционная БД для комплексных запросов и аналитики |
| Кэш/очереди | Redis 7 | Стандарт для кэша и простых очередей задач |
| Деплой | Docker Compose | Изоляция от других сервисов на VPS |
| Хостинг Mini App | Vercel | Бесплатный CDN, автодеплой из git, HTTPS из коробки |
| Платежи | ЮКасса | Единственный реальный вариант для РФ с поддержкой SBP |
| Состояние (Mini App) | Zustand | Минималистичный, без бойлерплейта |
| Графики | recharts | React-нативный, хорошая документация |

## Альтернативы, которые не выбрали

- **Telegram Bot API + Mini App** — MAX не Telegram, несовместимо
- **Python (FastAPI)** — нет общих типов с TypeScript фронтендом
- **MongoDB** — аналитика требует joins и агрегации, PostgreSQL лучше
- **Kubernetes** — избыточно для начального масштаба
