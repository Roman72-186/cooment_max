## Архитектурные решения

### Нет скрытого групчата
`POST /chats` в MAX API не существует — невозможно создать чат программно.
Комментарии хранятся только в PostgreSQL. Discussion chat не используется.

### open_app кнопка
MAX API требует `web_app` = зарегистрированный в MAX URL (space=TAMTAM).
Внешние Vercel URL не принимаются. Используем URL бота: `https://max.ru/id861708697380_bot`.
