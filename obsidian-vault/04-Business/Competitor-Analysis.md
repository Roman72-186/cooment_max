# Анализ конкурентов

## Tapbox.ru

Единственный известный конкурент на рынке MAX-комментариев.

| Параметр | Tapbox | MAX Comments (мы) |
|----------|--------|-------------------|
| Интерфейс | Кнопки в боте | Mini App — нативное ощущение |
| Онбординг | Ручные шаги в чате | Визуальный мастер в Mini App |
| Аналитика | Нет или минимум | Полная: ER, топ постов, лучшее время |
| Приватные каналы | Частично | Полная поддержка с первого дня |
| Монетизация | PRO тариф | PRO + реферальная программа |
| Дизайн | Генерик бот | Брендированный интерфейс |
| Архитектура | Монолит (предположительно) | Bot + Mini App + REST API (масштабируемо) |

## Наше конкурентное преимущество

1. **UX** — Mini App ощущается как нативная часть MAX, не как бот
2. **Аналитика** — у Tapbox её практически нет
3. **Онбординг** — визуальный мастер вместо инструкций в чате
4. **Приватные каналы** — полная поддержка
5. **Реферальная программа** — виральный рост

## Рынок

- 80M+ пользователей MAX
- 170,000+ публичных каналов
- MAX не планирует нативные комментарии в 2026
- Tapbox уже доказал, что спрос есть
