# Страницы Mini App

Mini App — основной пользовательский интерфейс платформы. Открывается внутри MAX.

## CommentsPage ★ Главная

**Путь:** `/` или `/?post_id=<ID>`
**Кто видит:** все подписчики канала

Функции:
- Отображение треда комментариев к посту
- Написать комментарий (требует авторизацию через Bridge)
- Ответить на комментарий (вложенность через `parent_id`)
- Скрыть комментарий (только автор или владелец канала)

## OnboardingPage

**Путь:** `/onboarding`
**Кто видит:** новые владельцы каналов

Мастер настройки (4–5 шагов):
1. Приветствие — зачем это нужно
2. Инструкция — как добавить бота как admin
3. Подтверждение — бот проверяет права
4. Настройка — выбор параметров (уведомления, модерация)
5. Готово — первый пост уже с кнопкой комментариев

## DashboardPage

**Путь:** `/dashboard`
**Кто видит:** владельцы каналов

- Список подключённых каналов
- Краткая статистика: посты, комментарии, подписчики
- Кнопки: перейти в канал, открыть аналитику, настройки

## AnalyticsPage (только PRO)

**Путь:** `/analytics/:channelId`
**PRO-gate:** для FREE показывается размытый интерфейс + кнопка «Купить PRO»

- Графики: просмотры, комментарии, реакции по дням
- Engagement Rate (ER)
- Топ постов по активности
- Лучшее время для публикации

## PricingPage

**Путь:** `/pricing`
- Сравнение FREE и PRO
- Кнопка «Купить PRO» → запускает платёжный флоу ЮКасса
- Отображение реферального кода текущего пользователя

## SettingsPage

**Путь:** `/settings/:channelId`
- Уведомления о новых комментариях
- Фильтрация мата (вкл/выкл)
- Список заблокированных пользователей
- Отключить бота от канала
