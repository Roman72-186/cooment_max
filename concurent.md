## 1. О продукте

PostX — бот для управления каналами в MAX:
- Отложенная публикация постов
- Комментарии к постам (через кнопку под постом)
- Интеграция с Telegram (экспорт постов из TG-канала в MAX-канал)
- Реклама, статистика, ссылка наблюдателя
- Личный кабинет: https://max.postxbot.app/
- Бот бесплатный, платные функции не планируются

Смежные продукты команды:
- @ChatKeeperBot — модератор чатов с аналитикой и AI
- @easymoderbot — компактный мобильный модератор чатов
- Каталог каналов MAX: https://max.postxbot.app/catalog

## 2. Ключевые проблемы пользователей

### 🔴 КРИТИЧНЫЕ

#### 2.1. Отсутствие уведомлений о новых комментариях
- Бот `@postingxnotificationsbot` был удалён платформой MAX и не восстановлен
- Пользователи вынуждены вручную заходить и проверять комментарии
- Из-за этого минимум один пользователь (Игорь Горев) **удалил бота** из канала
- Статус: команда работает над новой механикой уведомлений, анонс будет в канале новостей
- Цитата пользователя: «удалил этого бота из канала, потому что в нем недостаточно функционала, а также он не присылает уведомления о новых комментариях»

#### 2.2. Невозможность редактировать пост с открытыми комментариями
- Ограничение платформы MAX: нельзя редактировать пост, если под ним есть кнопка с комментариями
- Текущий workaround: сначала удалить комментарии → отредактировать → комментарии не вернуть
- Если пост создан через бота — можно редактировать в ЛК без удаления комментариев
- Пользователи путаются в этом разграничении и теряют комментарии

### 🟡 СРЕДНИЙ ПРИОРИТЕТ

#### 2.5. Кнопка комментариев появляется, но не кликабельна
- Причина: бот не имеет права «редактирование сообщений» в канале
- Пользователи не понимают, почему кнопка есть, но не работает
- Решение: назначить боту нужные права + /reload

#### 2.6. Белый экран при назначении бота администратором
- Баг: у одного пользователя при попытке назначить @postingxbot админом — белый экран
- Другим пользователям права выдаются нормально
- Причина не установлена, решение в чате не найдено

#### 2.7. Нет агрегации всех комментариев в одном месте
- Пользователи хотят видеть все комментарии ко всем постам в одном интерфейсе
- Текущее состояние: невозможно
- Запрос от Александра Курганова

#### 2.8. Нет пересылки из Telegram-группы в MAX-канал
- Бот работает только с каналами, группы не поддерживаются
- Миляуша Хасанова хотела пересылку из TG-группы в MAX-канал — невозможно

#### 2.9. Нельзя изменить время удаления на уже опубликованном посте
- Запрос пользователя Игоря — остался без ответа
- Предположительно функция недоступна

#### 2.10. Комментарии не работают для репостов
- Системное ограничение: комментарии не работают для репостов, где виден источник
- Пользователи не знают об этом заранее и считают это багом

## 4. Частые вопросы (FAQ — для обучения бота/документации)

| Вопрос | Ответ |
|---|---|
| Как подключить комментарии? | Добавить @postingxbot в админы канала с правом «редактирование сообщений» → переслать пост → в ЛК включить «Автоматические комментарии» → Сохранить |
| Как редактировать пост с комментариями? | Если пост создан через бота — ссылку на пост прислать боту или в ЛК. Если не через бота — сначала удалить комментарии |
| Как включить пересылку из TG в MAX? | @postx добавить в TG-канал → получить код в MAX-боте → вставить код в @postx |
| Бот бесплатный? | Да, полностью бесплатный |
| Почему нет уведомлений о комментариях? | Бот уведомлений удалён платформой MAX. Новая механика в разработке |
| Комментарии не работают в приватном канале? | Нужно убедиться, что бот добавлен и настроен в ЛК. Если посты содержат ссылки на другие каналы — включить тумблер «Разрешить комментарии к постам с посторонними MAX-ссылками» |
| Кнопка комментариев есть, но не кликается? | У бота нет права «редактирование сообщений». Назначить → /reload |

## 5. Технические детали бота

- Команда `/reload` — обновляет список администраторов
- Команда `/start` → «Личный кабинет» — основной интерфейс управления
- Комментарии появляются с задержкой до 1 минуты после публикации
- Комментарии не работают для репостов (где виден источник)
- Редактирование постов через бота: прислать ссылку на пост боту или через ЛК → calendar
- Для обновления прав бота в канале: /reload
