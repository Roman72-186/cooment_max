# .impeccable.md — MAX Comments Design Context

## Design Context

### Users
Два равноценных сегмента:
- **Читатели/подписчики каналов**: открывают Mini App тапом на кнопку «Комментарии» под постом в MAX. Мобильный контекст, на ходу, быстрое чтение и написание комментария. Задача — участвовать в дискуссии.
- **Владельцы каналов**: управляют каналом через Dashboard, Analytics, Settings, Inbox. Более вдумчивая сессия, но всё равно мобильная. Задача — понять что происходит на канале, настроить поведение.

Все пользователи — русскоязычные, мобильный MAX мессенджер, тёмный OLED-экран телефона чаще всего.

### Brand Personality
**Лаконично. Функционально. Фокусировано.**

Минимум функций — в хорошем смысле: каждый экран делает ровно одно дело, без лишнего шума. Не пытается выглядеть "крутым" — просто работает хорошо.

### Aesthetic Direction
- **Тема**: Dark only (пользователи в мессенджере, тёмный интерфейс вокруг)
- **Стиль**: Нейморфизм на тёмной основе — уже реализован, сохранять и улучшать
- **Акцент**: Фиолетовый (#7c4dff) — единственный яркий цвет
- **Типографика**: Системный шрифт сейчас — допустимо для Mini App внутри мессенджера (нет загрузки шрифтов)
- **Требования a11y**: WCAG AA обязательно (контраст 4.5:1, touch targets 44px, ARIA)

### Design Principles
1. **Один экран — одна задача**: CommentsPage — только комментарии. Dashboard — только обзор. Не смешивать.
2. **Скорость важнее красоты**: Оптимистичное обновление UI, ни одного лишнего состояния загрузки где можно обойтись без него.
3. **WCAG AA без компромиссов**: Контраст, touch targets, ARIA — не опциональные улучшения.
4. **Нейморфизм с умом**: Тени только где они несут смысл (нажато/не нажато). Не для украшения.
5. **Русский язык как первый**: Все тексты, ошибки, empty states — на живом русском, не калька с английского.
